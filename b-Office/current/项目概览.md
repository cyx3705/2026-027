# HistoryPortunus 项目概览

更新日期：2026-08-30

HistoryPortunus 1.0.6 是 HistoryVulcan 的对外传输模块，向本机前端提供回环 Web 接口，并向 agent 提供 MCP 接口。它以 HistoryVulcan 5.1.0 及以上的已发布快照为唯一宿主基线。

模块只依赖宿主 Core 中的命令总线和命令注册器。MCP schema、外部调用可见性、会话、审计与传输设置由模块自身维护；包不包含任何 `HistoryVulcan.*.dll`。

默认随宿主启动 MCP 与 Web，固定监听 `127.0.0.1:8777` 和 `127.0.0.1:8938`；端口占用时失败而不漂移。MCP 本机回环不持券，启动后把 Cursor `%USERPROFILE%\\.cursor\\mcp.json` 的 `history-vulcan` 写成当前 url。设置文件中的 `mcp.autostart`、`web.autostart` 可分别关闭自启动。
